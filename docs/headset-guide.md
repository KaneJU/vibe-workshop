# 戴著眼鏡創作：使用者指南（手機＋紙盒眼鏡）

把手機橫放進紙盒眼鏡（Cardboard 一類），坐著轉頭看作品，手伸到手機背面的鏡頭前操作。自由工坊與創作世界（`/?create`）都能用；這份指南以創作世界為主。

> 還沒驗證過：真的 iPhone＋紙盒鏡片的清晰度、雙眼融合、舒適度、發熱。下面的數值都是可以調的起點，不是任何一款手機或鏡片的認證值。

## 1. 裝盒前檢查（手機還拿在手上時做）

按頂列「👓 眼鏡」，面板最上面是「裝盒前檢查」。每一項都要**實際按一下試**才會通過；沒試的標「未測」，不會因為是 https 就全部打勾。

| 項目 | 怎麼試 | 通過的意思 |
|---|---|---|
| 🔒 安全連線 | 自動 | 頁面是 https（或這台電腦本機）；iPhone 只在安全連線給鏡頭、動作感測、語音 |
| 🎙 語音 | 按「說一句試試」，說一句話 | 真的辨識到字，記下多久出第一個字、整句（聽到的字只顯示，不保存） |
| 📷 後鏡頭 | 按「開鏡頭預覽」 | 看得到後鏡頭畫面、量到解析度與每秒張數 |
| 🧭 動作感測 | 按「轉一轉手機」，轉動手機 1.5 秒 | 收到感測資料（iPhone 會先問權限） |
| 📱 方向 | 自動 | 手機橫著 |
| 👀 左右眼 | 要人看 | 勾「進去先看校正圖」戴上：左眼只看到 L、右眼只看到 R，再回來勾「看過了」 |
| ✋ 手勢模型 | 自動 | 伺服器上有手勢模型檔 |
| 🔌 你的 Codex | 自動（創作世界） | 你自己的 connector 在線；沒連上也能戴著看、玩，但說了只會排隊，不會借用別人的 Codex |

按「開始」時，預覽用的鏡頭會先關掉，讓給手勢辨識。

## 2. 戴上之後

- **低頭看選單**：平常只有一個小小的「☰ 選單」（不擋地上的作品）；盯著它 1.5 秒或用手指著捏一下就展開。按鈕一樣盯著 1.5 秒或捏一下就按下；視線和手都離開 3 秒，選單會自己收起來。展開的選單有底板，捏在選單上不會穿過去點到後面的作品。
- **最上面的模式牌**一直寫著「現在說話會做什麼」：`✨ 說話＝做新作品` 或 `✏️ 說話＝改「某作品」v3`。
- **說話**：點一下螢幕（或紙盒的觸控鈕）開始，說完自動送出；再點一下也會停止。說話的那一刻就記下「在哪一層、改哪一件、哪一版」，說到一半換層、捏到別的作品都不會改錯。
- **新作品／修改**：用手捏一下作品＝選取它（也是點它）；選取**不會**自己變成修改。要改它，低頭選「✏️ 改」，模式牌變黃再說。改選別的作品會回到新作品。
- **取消**：選單「✕ 取消需求」——正在說的那句當場丟掉；不然取消還沒做完的需求。離開眼鏡模式、切到背景時，正在說的那句也會丟掉，回來不會補送。
- **方向鍵**：選單「🎮 方向鍵」打開後，視線下方會有 ▲ ◀ ⚡ ▶ ▼。手指著鍵捏住＝按住，捏著滑到別的方向就換（滑過中間的 ⚡＝暫時不按），張開手指放開；⚡ 要直接捏。手不見、離開眼鏡、換層、切到背景時一律放開。方向鍵開著時，選單會變淡：要按選單就低頭看著它。
- **子世界**：選單「🌀 子世界…」→「＋ 開子世界」（自動取名「第 N 層 M 號」，不用打字）→「進入〈…〉」；「⬑ 回上一層」回去。「🧩 放作品…」列出作品庫（最新的在前），在裡面做的作品回到外層也放得出來。
- **更多**：「↶ 退回 v…」把選取的作品換回上一版（存檔格式一樣才會帶著現在的狀態退回）、「⟳ 回正」、「▦ 校正圖」、「◎ 對位檢查」、「✕ 離開眼鏡」。按住螢幕 1.2 秒也會直接離開。
- 作品自己的 HUD（分數、剩幾條命）在右邊。

### 語音的限制（照瀏覽器的實際規則）

- 瀏覽器的語音辨識要**安全連線**、**麥克風授權**、頁面看得見。iPhone 上要用 Safari 本身；App 內建瀏覽器、加到主畫面的網頁 App 常常不能用。
- 凝視、捏合是這個遊戲自己算出來的動作，**不是瀏覽器認可的使用者手勢**。被拒過、或很久沒用時，瀏覽器只接受真的點螢幕才會開始聽，所以「說話」以點螢幕（或會碰到螢幕的紙盒觸控鈕）為準；選單的「🎙 說話」只有在麥克風已經允許時才會直接試，不行就提示你點螢幕。
- 這裡不另外錄音、不存音檔；瀏覽器的辨識不一定在手機上處理（可能送到瀏覽器廠商的服務）。不支援時可以摘下眼鏡打字。

## 3. 鏡頭位置（對位）與鏡片設定

手的位置是用後鏡頭看到的，所以要知道**鏡頭相對兩眼中間在哪裡**。面板「鏡頭與手」可以調、會存在這台裝置：

| 設定 | 範圍 | 怎麼量 |
|---|---|---|
| 鏡頭左右（右為＋） | −0.10～＋0.10 m | 戴好時，後鏡頭在兩眼中線的左邊或右邊多少 |
| 鏡頭上下（上為＋） | −0.10～＋0.10 m | 後鏡頭比眼睛高還是低 |
| 鏡頭在眼前多遠 | 0.02～0.15 m（預設 0.07） | 眼睛到鏡片＋鏡片到螢幕＋手機厚度 |

**對位檢查**（戴著，選單「⚙ 更多…」→「◎ 對位檢查」）：眼前 40 公分會出現黃色圓圈，把捏合的指尖放到圓圈中間、捏住 1 秒，會顯示差幾公分與建議的左右／上下偏移，可以按「✓ 套用」或「↺ 鏡頭偏移重設」。遠近的差只當參考（手的遠近是單眼估計）。這只校正**鏡頭位置**，不是鏡片光學校正。

「鏡片與畫面」裡的「虛擬瞳距」是畫面上兩個虛擬眼睛的距離，**不是**鏡片位置；鏡片沒對準眼睛要調紙盒本身。目前不支援掃描 Cardboard 的 QR 碼自動套用鏡片參數。

## 4. 紙盒原型（先做可調的）

手機、保護殼、鏡片還沒定之前，先做**可以調**的原型，不要直接照某一款手機裁死：

1. 一組成對的 VR 鏡片和鏡架（有規格最好）、硬紙板或泡棉板、魔鬼氈、軟墊。
2. 手機橫放、螢幕朝眼睛、**後鏡頭外露**（開大一點的窗，洞壁不要擋到鏡頭視野）。
3. 手機托架做成可前後移動，用來對焦；中間加遮光隔板，左右眼各看各的半邊。
4. 留一個側開口（或會碰到螢幕的觸控鈕）用來點螢幕說話。
5. 先手持試：清楚、看得到 L／R、手勢辨識正常，再加頭帶。頭暈、重影、手機過熱就停下。

量好、記下來（之後才做得出 1:1 的尺寸圖）：

| 量測欄位 | 數值 |
|---|---|
| 手機型號、有沒有保護殼 | |
| 機身（含殼）長 × 寬 × 厚（mm） | |
| 後鏡頭模組位置與凸出高度 | |
| 發光螢幕的寬 × 高（mm） | |
| 鏡片型號／焦距、兩片中心距（mm） | |
| 鏡片到螢幕距離（mm） | |
| 眼睛到鏡片距離（mm） | |
| 戴好時後鏡頭相對兩眼中間：左右／上下／前後（mm） | |
| 你的瞳距（mm） | |

## 5. 驗收摘要

裝盒前檢查最下面的「📋 驗收摘要」在**這台手機上**產生，可以複製或下載 JSON：裝置／瀏覽器版本（由瀏覽器自己回報）、設定、權限與每一項的實測結果、上一次戴著的幀時間與手勢辨識延遲、語音延遲、還沒測的項目。**不含**影像、聽到的話、cookie、配對碼、token、創作者 id、connector 名稱。摘要只說明這台瀏覽器量到什麼；是不是真的手機＋紙盒＋鏡片，要由人確認。
